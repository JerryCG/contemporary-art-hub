How to open the Hub

The new site is an app, not a single index.html you can double-click. Pick one door:

Original site (this works offline) New museum on GitHub

On this computer, double-click dev.cmd, then open http://localhost:3000 for the full new museum (including Studio, if you add an API key).

After you push to GitHub and enable Pages, the public address is:
https://jerrycg.github.io/contemporary-art-hub/
